PROMART · En producción

Conciliación diaria de tesorería

Automation Anywhere A360 · Excel · aplicaciones internas

Problema

La conciliación diaria requería la intervención de 38 tesoreras y utilizaba información distribuida entre tres aplicaciones internas, Excel y correo.

Análisis

Revisé qué tareas podían ejecutarse automáticamente y cuáles debían permanecer bajo supervisión humana.

Hallazgo

La ejecución repetitiva podía trasladarse a un bot sin eliminar el control de las personas responsables del proceso.

Decisión y ejecución

Desarrollé la automatización en Automation Anywhere A360 para realizar la conciliación y dejar el resultado preparado para supervisión.

Resultado comprobado

La operación pasó de requerir la intervención de 38 tesoreras a ser supervisada por 3 personas.

PROMART · En producción

Carga y validación de promociones

.NET · Oracle · SQL Server · GCP Cloud Run

Problema

Cada lote requería revisar precios, stock, márgenes, vigencias, combos, aportes y cartelería. El procesamiento diario tomaba 3 horas.

Análisis

Definí y validé las reglas comerciales que determinan cuándo una promoción puede procesarse y cuándo necesita revisión.

Hallazgo

Las excepciones comerciales no debían ocultarse ni aprobarse automáticamente. Necesitaban revisión humana y trazabilidad.

Decisión y ejecución

Validé un portal que aplica las reglas, consulta información en Oracle y SQL Server y separa las excepciones para revisión humana. El proceso registra la trazabilidad y genera resultados en Excel y JSON.

Resultado comprobado

El portal pasó a producción y redujo el procesamiento de cada lote diario de 3 horas a 2 minutos.

PROMART · Implementado

Contenido para productos

Python · OpenAI API · Microsoft Graph · GCP Cloud Run

Problema

La automatización anterior generaba nombres, descripciones y HTML para productos en Automation Anywhere. El proceso debía migrarse a un servicio en la nube.

Análisis

Identifiqué los controles necesarios para validar el Excel de entrada, los datos de cada producto, la respuesta del modelo y el HTML generado.

Hallazgo

Las respuestas del modelo no podían publicarse directamente. Cada resultado necesitaba validación de estructura, formato y contenido.

Decisión y ejecución

Migré el proceso a Python en GCP Cloud Run. El flujo procesa productos en paralelo, consulta OpenAI API y utiliza Microsoft Graph para descargar y publicar archivos en SharePoint.

Resultado comprobado

El reemplazo quedó implementado. Registra filas procesadas y fallidas, valida el contenido generado y publica el resultado en SharePoint.
